# Clip A8 sur le réseau du collège

Pour qu'un élève regarde le clip seul (au casque), copier **ensemble, dans un même dossier** du partage réseau :

```
A8-clip-methode/
├── clip_A8.html          ← la page à ouvrir (double-clic)
├── clip_A8.mp4           ← version standard (2 min, 11 Mo)
└── clip_A8_adapte.mp4    ← version adaptée, plus lente (3 min, 12 Mo)
```

Ces trois fichiers suffisent : la police Luciole, les sous-titres et la transcription sont **dans** la page.
Ne pas renommer les vidéos (la page les cherche sous ces noms, dans son propre dossier).

Fichiers facultatifs, pour un autre lecteur (VLC…) : `clip_A8.vtt` et `clip_A8_adapte.vtt` (sous-titres),
`clip_A8_transcription.md` et `clip_A8_adapte_transcription.md` (texte).

En ligne, la même page : https://blanchardromain-cyber.github.io/techno-p11-eau/ressources/a8-declencheur/medias/clip_A8.html
(ajouter `#transcription` à l'adresse pour l'ouvrir avec la transcription dépliée).

Navigateur : Chrome, Edge ou Firefox récents. Si le poste ouvre le `.html` avec un autre programme : clic droit → Ouvrir avec → Chrome.
